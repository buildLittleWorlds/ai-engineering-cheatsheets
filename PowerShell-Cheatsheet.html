PowerShell
Cheat Sheet

Commands are ordered roughly from most to least useful for everyday file work. Start at the top, practice the examples, and use the full command names when writing scripts.

How to read this: gci is an alias for Get-ChildItem. Parameters such as -Force change a command’s behavior. A dot (.) means the current folder, and two dots (..) mean its parent.

1. Navigate and list files

The commands you will probably use in nearly every session.

#CommandAliasExampleWhat it does
1Get-ChildItemgci, ls, dirgci -ForceLists items in a location. -Force includes hidden items; -Recurse descends into subfolders.
2Set-Locationsl, cd, chdircd '.\My Folder'Changes the current location. Use cd .. to move to the parent folder.
3Get-Locationgl, pwdpwdShows the full path of the current location.
4Get-Itemgigi '.\notes.txt'Gets one specific file or folder as an object, including its properties.
5Push-Locationpushdpushd 'C:\Temp'Saves the current location on a stack and moves somewhere else.
6Pop-LocationpopdpopdReturns to the most recently saved location from Push-Location.
7Resolve-PathrvpaResolve-Path .Resolves a relative or wildcard path into its full path.
8Test-PathnoneTest-Path '.\notes.txt'Returns True or False to indicate whether a path exists.

2. Create, copy, move, and delete

Deletion is permanent; PowerShell normally does not send items to the Recycle Bin.

#CommandAliasExampleWhat it does
9New-Itemnini notes.txtCreates an item. Add -ItemType Directory for a folder; mkdir folder is the concise folder form.
10Copy-Itemcpi, cp, copycp '.\a.txt' '.\backup\'Copies files or folders. Use -Recurse to copy a folder and its contents.
11Move-Itemmi, mv, movemv '.\a.txt' '.\archive\'Moves an item to another location; it can also rename an item.
12Remove-Itemri, rm, delri '.\old' -Recurse -ForceDeletes items. -Recurse includes children and -Force includes hidden/read-only items.
13Rename-Itemrni, renrni 'old.txt' 'new.txt'Changes an item’s name without moving it to another folder.
14Set-Contentsc'hello' | sc '.\note.txt'Writes content to a file, replacing anything already there.
15Add-Contentac'another line' | ac '.\note.txt'Appends content to the end of a file.
16Clear-Contentclcclc '.\note.txt'Empties a file but leaves the file itself in place.
17Join-PathnoneJoin-Path $HOME 'notes.txt'Combines path components safely.

3. Read and inspect things

#CommandAliasExampleWhat it does
18Get-Contentgc, cat, typegc '.\note.txt'Reads file content. By default, each text line becomes a pipeline object.
19Get-Membergmgi '.\note.txt' | gmShows the properties, methods, and type of objects coming through the pipeline.
20Select-Objectselectgci | select Name, LengthSelects properties or a number of items, such as -First 5 or -Last 2.
21Measure-Objectmeasuregci -File | measure Length -SumCounts objects and can calculate sum, average, minimum, and maximum.
22Get-AclnoneGet-Acl '.\note.txt'Shows an item’s access permissions and owner.
23Get-FileHashnoneGet-FileHash '.\download.zip'Calculates a cryptographic checksum, useful for checking file integrity.
24Compare-Objectcompare, diffCompare-Object $a $bCompares two collections of objects and identifies differences.

4. Search, filter, sort, and transform

#CommandAliasExampleWhat it does
25Where-Objectwhere, ?gci | ? Length -gt 1MBFilters pipeline objects by a condition.
26ForEach-Objectforeach, %gci | % NameRuns an operation for every pipeline object.
27Sort-Objectsortgci | sort Length -DescendingSorts objects by one or more properties.
28Select-Stringslssls 'error' '.\*.log'Searches text for a word or regular-expression pattern.
29Group-Objectgroupgci | group ExtensionGroups objects that share a property value and counts each group.
30Get-Uniquegu$names | sort | guRemoves adjacent duplicate values; sort first to group duplicates together.

6. Help, history, formatting, and web

#CommandAliasExampleWhat it does

41Get-Commandgcmgcm '*file*'Finds commands by name, verb, noun, type, or module.

46Format-Tableftgci | ft Name, LengthFormats final display output as a table. Keep formatting commands at the end of a pipeline.
47Format-Listflgi . | fl *Formats an object as a vertical property list; * requests all properties.
48Export-Csvepcsvgci | Export-Csv files.csvSaves objects as CSV rows for a spreadsheet or later processing.
49Invoke-WebRequestiwriwr 'https://example.com'Makes a web request and returns response details and content.
50Invoke-RestMethodirmirm 'https://api.example.com/items'Calls a web API and converts JSON responses into PowerShell objects.
Safety habit: preview risky commands first. For many commands, add -WhatIf, for example Remove-Item '.\old' -Recurse -WhatIf. Aliases are convenient at the prompt; full cmdlet names are clearer in scripts.
