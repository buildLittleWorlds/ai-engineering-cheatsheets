# AI Engineering Cheatsheets

Searchable, standalone HTML references for PowerShell and Git.

Both sheets lead with a guided small-program workflow: run `assistant.py`, change `reference.txt`, inspect the manually transferred prompt, and preserve two selected-source checkpoints. Broader shell commands and optional Git workflows follow below. The example keeps reference material outside Git; the guidance also applies to other small projects.

- [Open the site](https://buildlittleworlds.github.io/ai-engineering-cheatsheets/)
- [PowerShell](https://buildlittleworlds.github.io/ai-engineering-cheatsheets/PowerShell-Cheatsheet.html)
- [Git: 10 everyday workflows](https://buildlittleworlds.github.io/ai-engineering-cheatsheets/Git-Cheatsheet.html)

## Publishing

GitHub Pages deploys from the root of `main`. Edit the HTML files, commit, and push to update the site. There are no dependencies or build steps. `.nojekyll` keeps these files as plain static assets.

Each cheatsheet also works when downloaded and opened locally in a browser.
